# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in the Creatio AI App Development Toolkit, please **do not** open a public GitHub issue, discussion, or pull request.

Instead, email a detailed report to:

**support@creatio.com**

Please include, where possible:

- A description of the issue and its potential impact.
- Steps to reproduce, including the toolkit version (`.release-manifest.json` / GitHub release tag), the host coding agent (Codex, Claude Code, Cursor, GitHub Copilot CLI), and your operating system.
- Any proof-of-concept code, logs, or screenshots that help reproduce the issue.
- Whether you would like to be credited in the eventual fix announcement.

We will acknowledge your report and coordinate a fix and disclosure timeline with you.

## Supported Versions

Security fixes are applied to the latest released version of the toolkit. Older releases are not patched separately — please upgrade to the current release before reporting issues that may already be fixed.

## Scope

This policy covers the source code published in this repository and the release assets produced from it. Vulnerabilities in the Creatio platform itself, in [clio](https://github.com/Advance-Technologies-Foundation/clio), or in third-party AI coding agents (Codex, Claude Code, Cursor, GitHub Copilot CLI) should be reported to their respective maintainers.
