A countdown timer, if the answer uses one, is for a near-term date users act on (next site inspection due), not for the planned end date that is a year or more away. A timer that is used has a visible caption saying what it counts down to, and the answer says how an overdue state looks (for example a red value or an "Overdue" text). An answer that puts a countdown timer on the planned end date fails. An answer with no timer at all passes this criterion only if it shows the inspection due date where it is seen on opening the page.
