Every chart or metric the answer proposes names the question it answers (for example "is the project within budget?"). A budget-against-actual comparison shows both series, budget and actual cost. Charts about work packages or materials sit on the tab that holds that list, next to the data, rather than in a separate Analytics tab holding only one or two charts. A metric that only repeats a field's value (a tile showing the budget alone) fails.
