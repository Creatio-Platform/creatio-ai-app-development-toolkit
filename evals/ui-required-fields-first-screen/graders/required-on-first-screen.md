All eight required fields — contract number, lessee, vehicle, start date, end date, monthly payment, insurance policy number, insurance valid until — are placed where the user sees them on opening the page: the header or top island, the left profile column, or the first tab. None of them sits only on a second or later tab (for example an "Insurance" tab) or in a collapsed panel. If the answer keeps an insurance group, the two required insurance fields are still on the first screen.
