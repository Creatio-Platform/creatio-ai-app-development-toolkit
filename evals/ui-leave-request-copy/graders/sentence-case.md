Every caption, title and message is in sentence case: only the first word and proper nouns start with a capital letter ("Send for approval", "Cancel approved leave?"). Fail only if a string uses Title Case ("Send For Approval") or ALL CAPS. Placeholders such as {0} and resource keys such as `CancelLeaveButtonCaption` are not captions and do not count.
