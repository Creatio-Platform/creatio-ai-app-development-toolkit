# Agent 04 — Implementation Orchestrator

## Role

Read plan, generate all package files using skills, validate output.

## Input/Output

- **Input:** `output/<AppName>/plan.md`
- **Output:** `output/<AppName>/packages/<PkgName>/` — complete package

## Context

Read `AGENTS.md` for Context Files Reference and Skills list.

**Skills:**
- `skills/entity-creation.md` — entity schemas
- `skills/page-creation.md` — page schemas  
- `skills/addon-creation.md` — addon schemas
- `skills/data-bindings-creation.md` — data bindings

**Templates:** `templates/` for exact format reference.

---

## Steps

### 1. Parse plan.md

Extract: package name/UId, all entities, pages, addons, bindings, seed data with GUIDs.

### 2. Create Package Skeleton

```bash
clio new-pkg <PkgName>
```

### 3. Modify descriptor.json

Edit `output/<AppName>/packages/<PkgName>/descriptor.json`:
- Set `PackageVersion` to `"8.1.0"`
- Set `Maintainer` to `"Customer"`
- Set `DependsOn` to `[]`

### 4. Clean Up Skeleton

Remove unnecessary files generated by `clio new-pkg`:
- `*.csproj`
- `*.sln`
- `packages.config`
- `Files/` directory
- `Properties/` directory
- `Resources/` directory
- `SqlScripts/` directory
- `Assemblies/` directory
- Any `placeholder.txt` files

Keep only:
- `descriptor.json`
- `Schemas/` directory
- `Data/` directory

### 5. Generate Entities (Group 1)

Invoke the **Entity Creation** skill (`skills/entity-creation.md`) for each entity defined in plan.md.

**Order matters**: Generate lookup entities (BaseLookup) first, then main entities (BaseEntity).

For each entity, the skill creates:
```
Schemas/<EntityName>/
  descriptor.json
  metadata.json
```

### 6. Generate Pages (Group 2)

Invoke the **Page Creation** skill (`skills/page-creation.md`) for each page defined in plan.md.

For each page, the skill creates:
```
Schemas/<PageName>/
  descriptor.json
  metadata.json
  <PageName>.js
```

### 7. Generate Addons and Data Bindings (Group 3)

Invoke both skills in parallel:

**Addon Creation** (`skills/addon-creation.md`):
```
Schemas/<AddonName>/
  descriptor.json
  metadata.json
```

**Data Bindings Creation** (`skills/data-bindings-creation.md`):
```
Data/<BindingName>/
  descriptor.json
  metadata.json
  data.json
```

This includes:
- SysModuleEntity records
- SysModule records
- Lookup seed data records (one data folder per lookup)

### 8. Validate Output

Run these validation checks before declaring success:

#### File Structure Validation
- [ ] `descriptor.json` exists at package root
- [ ] Every entity from plan.md has a `Schemas/<EntityName>/` directory with `descriptor.json` and `metadata.json`
- [ ] Every page from plan.md has a `Schemas/<PageName>/` directory with `descriptor.json`, `metadata.json`, and `<PageName>.js`
- [ ] Every addon from plan.md has a `Schemas/<AddonName>/` directory with `descriptor.json` and `metadata.json`
- [ ] Data binding directories exist under `Data/`

#### Cross-Reference Validation
- [ ] Entity UIds referenced in page JS files match entity UIds in plan.md
- [ ] Page UIds in SysModule data bindings match page UIds in plan.md
- [ ] Entity UIds in addon descriptors match entity UIds in plan.md
- [ ] SysModuleEntity.SysEntitySchemaUId matches the target entity UId

#### JSON Validation
- [ ] All `.json` files are valid JSON (parseable without errors)
- [ ] All `.js` files have valid syntax

#### GUID Uniqueness
- [ ] No duplicate GUIDs exist across all generated files
- [ ] All GUIDs in generated files match those in plan.md

## Generation Order Summary

```
1. Lookups     (BaseLookup entities — no dependencies)
2. Entities    (BaseEntity entities — may reference lookups)
3. List Pages  (reference entities)
4. Form Pages  (reference entities)
5. Addons      (reference entities + form pages)
6. Data Bindings:
   a. SysModuleEntity (reference entities)
   b. SysModule (reference SysModuleEntity + pages)
   c. Lookup Seed Data (reference lookup entities)
```

## Completion Criteria

✅ All schema directories created with correct files  
✅ All cross-references validated  
✅ All JSON files are valid  
✅ No duplicate GUIDs  
✅ Package is ready for `clio push-pkg`
