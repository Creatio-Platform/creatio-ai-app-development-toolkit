First, three concepts

Skill, workflow and engine are very simple

S

Skill

A set of knowledge and rules for a specific role: what to read, what to do and what not to miss.

As a profession: analyst or designer
W

Workflow

Sequence of stages. He decides who to call, in what order and when to repeat the step.

As a pipeline or work script
✓

Engine

Calculates whether everything is taken into account, generates a plan and compares it with the actual result.

As an independent quality controller
01 · Common languageSkill knows · Workflow organizes · Engine checks
What to say: Skill is not a separate bot, but an instruction for a role. Workflow is not knowledge, but the order of work. Engine does not reason for them: it calculates completeness and forms an objective verdict.

Skill 2

classic-ui-expert is a translator from code to business behavior

PHASES 1–2

Find everything

Detects all pages and reads the full chain of their Classic extensions.

PHASES 3–5

Understand

Lists each piece of code, groups them into behaviors, and finds external dependencies.

PHASE 6

to describe

Creates cards: when a behavior is triggered, what it does, why it is needed, and how to test it.

Important: this skill does not start a separate workflow. It is called by agents within the analysis workflow.
07 · Code → understandable behaviorIf there is no proof, he honestly records the unknown
What to say: Classic UI Expert is like an analyst who reads the program and writes instructions for the future developer. It does not invent an answer: it captures the unknown behavior as a gap with an explanation that needs to be checked.
Skill 3 + Workflow 2

freedom-build-executor is a build and independent verification pipeline

freedom-build-executor.workflow.jsLaunched only after approval of the plan
1

Reconcile

Check the plan, the queue and what has already been done.

2

Refs

Prepare the necessary instructions once.

3

Preflight

Close the issue with evidence before changes.

4

Build

Build one page.

5

Verify

Another agent reads the actual result.

6

Judge

A third agent assesses the sufficiency of the evidence.

7

Close

Final table or exact gaps.

If the page does not pass the check, the cycle is repeated for that page. After three unsuccessful attempts, she is not buried - she is "parked" for a clear reason.
08 · One page at a timeBuilder ≠ Verifier ≠ Judge
What to say: It is like a production line with independent control. The one who collected the detail does not rate himself. Another checks the fact, the third checks whether the evidence is sufficient. An unsuccessful result is returned for repair.
