Проблема

Міграція — це більше, ніж перенести поля

1

Повна структура

Вкладки, деталі, дочірні сторінки й різні типи карток.

2

Прихована логіка

Правила та поведінка можуть жити в інших Classic-схемах.

3

Правильний запуск

Створена сторінка ще має відкриватися для потрібного запису.

4

Доказ готовності

Успішне збереження не означає, що користувацький сценарій працює.

Тому наш результат — не «сторінка створена», а «весь погоджений сценарій перенесено й перевірено».
01 · Чому потрібен повний процесClassic → Freedom UI
Що сказати: На реальній сторінці важливі не лише видимі поля. Є успадкована логіка, дочірні форми, маршрути відкриття та поведінка, яку звичайна перевірка схеми не бачить.

Фінал

Готовність визначає перевірка, а не заява агента

✓

Plan vs Done

Наприкінці engine порівнює погоджений план із фактично створеними сторінками та зв'язками. Якщо щось відсутнє або не підтверджене, міграція не вважається завершеною.
