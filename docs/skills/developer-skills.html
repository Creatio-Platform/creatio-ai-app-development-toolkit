08 / Working agreements

The skills make the safe path obvious.

DO

Start from the user’s intent.

Let the request choose the entrypoint. Let the skill choose the evidence, gates, and implementation shape.

DON’T

Jump straight to a page body.

Skipping discovery hides ownership, package editability, responsive variants, resource bindings, and business decisions.

DO

Treat read-back as part of delivery.

Inspect the generated artifact, rendered page, or published article — not just the tool response.

DON’T

Confuse a plausible result with a proven one.

When a source is unavailable, say so. When a gate is blocked, fix the named gap or stop.
